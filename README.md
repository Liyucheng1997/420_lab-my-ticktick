# 我的滴答清单（网页版）

一个仿照滴答清单功能做的个人待办网页，纯 HTML + CSS + JavaScript，不需要安装任何依赖，数据保存在浏览器本地（localStorage）。

## 打开方式

- 在线使用：https://liyucheng1997.github.io/my-ticktick-web/ （手机也能打开，数据保存在各自的浏览器里）
- 直接双击 `index.html`，用 Chrome / Edge 打开即可。
- 或者在本目录运行本地服务器（系统通知在 `localhost` 下更可靠）：

```bash
python -m http.server 5173
```

然后访问 http://localhost:5173

> 注意：双击打开和用 localhost 打开是两个不同的“网站”，数据不互通。选定一种方式长期使用，并定期在「设置 → 导出备份」。

## 功能

| 模块 | 内容 |
| --- | --- |
| 任务 | 智能清单（今天 / 明天 / 最近7天 / 收集箱 / 所有）、自定义清单（带颜色）、标签、已完成、垃圾桶 |
| 智能识别 | 输入 `明天下午3点 开会 #标签 !高 ~清单名` 自动识别日期、时间、标签、优先级、清单；支持 `每天 / 每周一 / 每月15号 / 工作日` 重复，`下周三`、`3天后`、`11月20日` 等日期 |
| 任务详情 | 标题、描述、子任务（回车新增、退格删除）、日期 / 时间 / 提醒 / 重复、优先级、标签、所属清单、专注统计 |
| 排序分组 | 按时间（已过期 / 今天 / 明天 / 最近7天 / 更远 / 无日期）、按优先级、按标题、自定义拖动排序 |
| 拖放 | 拖到侧栏清单 = 移动，拖到今天 / 明天 = 改日期，拖到垃圾桶 = 删除，拖到日历格子 = 改日期，拖到四象限 = 改优先级 |
| 右键菜单 | 快速改日期、优先级，移动、打标签、复制、专注、删除 |
| 日历 | 月视图、周视图（时间轴），显示重复任务的后续日程，点击空白处快速新建 |
| 四象限 | 按优先级分为四个象限，可直接在象限内添加任务 |
| 番茄专注 | 番茄钟 / 正计时，自动休息、长休息，关联任务，今日 / 累计统计与专注记录 |
| 习惯打卡 | 每天或每周指定几天、每日多次目标、本周进度环、连续天数、最长连续、月历补打卡 |
| 提醒 | 到点弹出页面提示 + 提示音 + 系统通知（需授权） |
| 其他 | 搜索（Ctrl+K）、深色模式、导入 / 导出备份、撤销完成与删除、手机端适配 |

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl + K` 或 `/` | 搜索 |
| `N` | 新建任务 |
| `1` – `5` | 切换任务 / 日历 / 四象限 / 番茄 / 习惯 |
| `Delete` | 删除选中的任务 |
| `Esc` | 关闭弹窗、详情面板 |

## 目录

```
index.html        页面入口
css/tokens.css    设计变量（苹果式简约设计语言）
css/app.css       应用样式
js/util.js        日期、DOM 工具
js/store.js       数据层（任务、清单、标签、习惯、撤销）
js/parse.js       智能识别
js/ui.js          浮层、菜单、对话框、日期选择器、通知
js/detail.js      任务详情面板与通用任务操作
js/view-*.js      各个模块视图
js/app.js         应用外壳、拖放、搜索、设置、提醒
```
